# ZeroScript Update Notes

## Важно при обновлении ZeroScript

**Порядок закрытия: сначала всё, что НЕ является мостом, потом сам мост.**

1. **Закрыть окно `ZeroScript AI activity`** (процесс `powershell.exe`, запущенный с `zerolog.ps1`).
   Оно не держит порт 17613 и не мешает обновлению напрямую, поэтому гасится первым.

2. **Закрыть сам мост** — окно `ZeroScript Bridge` (процесс `python.exe` с `bridge.py`).
   Он держит порт 17613 и stdio-каналы MCP-серверов, поэтому его очередь — последняя.

3. Убедиться, что порт 17613 свободен: `netstat -aon | findstr :17613`

4. Обновить файлы / расширение.

5. Запустить `start.bat` заново.

### Почему такой порядок

Если убить мост первым, `zerolog.ps1` останется висеть и продолжит тейлить `logs/ai_actions.log` — при обновлении файлов это может дать конфликт блокировки или просто мусор в логе. Окно логов безвредно, и его закрытие первым ничего не ломает.

## Команды для закрытия

```
:: 1. Найти процессы
tasklist | findstr /I "python powershell"

:: 2. Сначала окно логов (powershell с zerolog.ps1)
taskkill /F /T /PID <pid_powershell>

:: 3. Потом мост (python с bridge.py)
taskkill /F /T /PID <pid_python>

:: 4. Проверить порт
netstat -aon | findstr :17613
```
